# 页面注入迁移资料

先读 [01_拼多多与抖音页面注入收发迁移手册.md](./01_拼多多与抖音页面注入收发迁移手册.md)。

- [02_核心源码全文.md](./02_核心源码全文.md)：拼多多、抖音收发与页面桥源码全文。
- [03_宿主接线与测试源码.md](./03_宿主接线与测试源码.md)：宿主参考、接口、原测试与配置。
- [04_源码清单与校验.md](./04_源码清单与校验.md)：SHA-256 与本轮离线测试结果。
- `源码快照/`：迁移用的原样静态 TS / JS 文件与配置参考。
- `源码清单.json`、`离线测试结果.json`：机器可读校验及测试记录。

拼多多默认方案是 **CDP 接收 + 同页发送**；抖音方案是 **Store / IM 页面桥**。可选的拼多多 Store hook 单独说明，不与默认方案混写。

`工具/` 是本机提取与隔离验证工作文件，引用本机 D 盘的依赖；不是目标软件的启动器。压缩迁移包只包含文档、源码快照和校验结果，不打包工具目录、依赖或运行数据。
