# FlowSheet 流光账单 · 银行流水 PDF 转 Excel（纯本地离线版）

把银行流水 PDF 在浏览器里整理成可核对、可导出的表格。解析只发生在本机内存，流水不会上传。

## 方式一：直接在线打开使用（纯本地浏览器内存解析，数据不上传）

[点击直接在线打开 FlowSheet 流光账单](https://htmlpreview.github.io/?https://github.com/gq741/-/blob/main/index.html)

GitHub Pages 地址：<https://gq741.github.io/-/>

## 方式二：下载离线单文件到电脑（断网可用，仅 42 KB）

[点击一键下载 `流光账单-银行流水PDF转Excel离线版.html`](https://raw.githubusercontent.com/gq741/-/main/%E6%B5%81%E5%85%89%E8%B4%A6%E5%8D%95-%E9%93%B6%E8%A1%8C%E6%B5%81%E6%B0%B4PDF%E8%BD%ACExcel%E7%A6%BB%E7%BA%BF%E7%89%88.html)

打开后按 `Ctrl+S` / `Cmd+S` 保存到桌面，双击即可在浏览器运行。页面右上角的「下载离线单文件 (.html)」也会把当前页面存成同一份离线文件。

## 三大核心功能

1. **本地解析银行流水 PDF**  
   拖入文本型流水 PDF，按文字坐标对齐成表格行。支持常见个人卡、企业对公回单，以及微信、支付宝交易明细。文件只在浏览器内存中读取。

2. **余额连续性勾稽**  
   逐行核验「上期余额 + 收入 − 支出 = 本期余额」。差额和疑似漏页会标红，方便对账。

3. **导出 Excel 与 CSV**  
   可导出 `.xls` 和 UTF-8 CSV。内置 **3 次免费导出额度**；额度用完后，可在页面内激活专业版以解除导出次数限制。校验在本地完成。

## 使用说明

1. 用方式一在线打开，或用方式二把离线文件保存到电脑后双击打开。
2. 选择或拖入银行流水 PDF。也可以先切换「招商银行个人流水」「工商银行对公流水」「微信/支付宝经营流水」查看演示效果。
3. 用搜索、收支方向和科目筛选核对明细，并查看「余额勾稽核验」列。
4. 点击「导出 Excel (.xls)」或「导出标准 CSV (UTF-8)」。未激活时每次导出消耗 1 次免费额度，共 3 次。
