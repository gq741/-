# 图灵办公 · 纯白极简离线工具矩阵（本地浏览器运行 · 数据不上传）

所有工具均采用纯前端本地浏览器内存解析与计算，无需联网上传任何财务或个人敏感数据，支持在线直接打开使用或一键下载单文件 `.html` 离线保存。共用 `TL320-XXXX-XXXX-XXXX` 通兑激活码解锁无限制专业版。

把银行流水 PDF 在浏览器里按坐标对齐整理成可核对、可导出的标准表格，逐行核验「上期余额 + 收入 − 支出 = 本期余额」连续性勾稽。

- **直接在线打开**：[https://htmlpreview.github.io/?https://github.com/gq741/-/blob/main/index.html](https://htmlpreview.github.io/?https://github.com/gq741/-/blob/main/index.html)

## 4. 赔偿金计算器 · 离职经济补偿金(N+1/2N)与加班费仲裁明细表 (`LaborCalc`)

依据《劳动合同法》第 47、40、87 条及社平工资三倍封顶规则，精确折算工龄 `N`（不满半年 0.5、满半年 1），自动计算 `N` / `N+1` / `2N` 经济补偿金、未休年假三倍工资差额及工作日/休息日/法定节假日加班费，一键生成可直接复制打印的《劳动人事争议仲裁申请书 · 请求事项与计算附表》。

- **直接在线打开**：[https://htmlpreview.github.io/?https://github.com/gq741/-/blob/main/labor-calc/index.html](https://htmlpreview.github.io/?https://github.com/gq741/-/blob/main/labor-calc/index.html)
